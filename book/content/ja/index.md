# AWS in Your Hands

**TypeScript でつくる、身近な AWS**

TypeScript、HTTP、Git、ふつうの Web アプリ開発には慣れている。けれど AWS のアカウント、IAM、ネットワーク、料金、運用は初めて。この本はそういう開発者のために書いています。

Cloudflare や Vercel を使っている人に、乗り換えを勧める本ではありません。それらは手軽で、開発体験もよいプラットフォームです。この本は、AWS も自分の道具として選べるようにするためのものです。AWS のほうが常に安い、速い、優れている、とは書きません。

読み終えたとき、作ったものについて次のことを説明できる状態を目指します。

- 何を作ったか、なぜその構成にしたか
- コードがどこで動いているか
- 何に料金がかかるか
- 手元で確かめられることと、実環境でしか確かめられないこと
- 本番で使うなら何を足すか
