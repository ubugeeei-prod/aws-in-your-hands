# AWS in Your Hands

**TypeScript でつくる、身近な AWS**

TypeScript も HTTP も Git も、ふつうの Web アプリ開発も慣れている。でも AWS のアカウント、IAM、ネットワーク、料金、運用は初めて。そんな開発者に向けて書いている本です。

Cloudflare や Vercel を使っている人に、乗り換えを勧める本ではありません。どちらも手軽で、開発体験もいいプラットフォームですよね。この本がやりたいのは、AWS も自分の道具として選べるようにすること。AWS のほうが常に安い、速い、優れている、とは書きません。

読み終えたとき、作ったものについてこんなことを説明できるようになっているのが目標です。

- 何を作ったか、なぜその構成にしたか
- コードがどこで動いているか
- 何に料金がかかるか
- 手元で確かめられることと、実環境でしか確かめられないこと
- 本番で使うなら何を足すか
