# AWS in Your Hands

**TypeScript でつくる、身近な AWS**

TypeScript、HTTP、Git、Web アプリの開発には慣れているけれど、AWS のアカウント、IAM、ネットワーク、料金、運用にはまだ触れたことがない開発者に向けて書いた本です。

Cloudflare や Vercel からの乗り換えを勧める本ではありません。どちらも始めやすく、開発体験のよいプラットフォームです。この本が目指しているのは、そこに AWS を加えて、作るものに合わせて選べるようにすることです。AWS のほうが常に安い、速い、優れているとは書きません。

読み終えたときに、自分が作ったものについて次のことを説明できるようになることを目標にしています。

- 何を作ったか、なぜその構成にしたか
- コードがどこで動いているか
- 何に料金がかかるか
- 手元で確かめられることと、実環境でしか確かめられないこと
- 本番で使うなら何を足すか

## 書けている範囲と、確かめた範囲

00章から 24章まで、25 章すべてに本文とサンプルがあります。ただし、書き上げたことと、動かして確かめたことは別で、確かめたのは手元のマシンで実行できる範囲までです。

- [00 Introduction](/ja/chapters/00-welcome.md)から [24 Self-hosting](/ja/chapters/24-celld.md)まで、どの章も手元の検査（`vp run check:all`）に通っています。検査の中身は、format と lint、型検査、テスト、CDK の synth、Lambda のバンドルの読み込み、本のビルドとリンクの検査です
- AWS には、どの章もまだ一度もデプロイしておらず、実行もしていません。本文にあるデプロイ後の手順は用意しただけで、通して実行できていません
- この本のサイトもまだ公開しておらず、公開 URL はありません

手元で確かめた内容は章によって違い、テストだけの章もあれば、サーバーを起動して `curl` やブラウザで操作した章もあります。章ごとの内訳は、各章の末尾にある「この章の検証メモ」に書きました。どのコマンドをいつ実行して何が通ったか、何がまだ残っているかは、[検証記録](/ja/reference/validation.md)にまとめてあります。

## コードの置き場所

本文で説明するコードは、すべてこの本と同じリポジトリにあります。本文に載っているコードは実際のファイルから取り込んだもので、説明のために書き直した断片ではありません。どの節がどのファイルに対応するかは、各章の末尾に載せています。
