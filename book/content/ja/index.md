# AWS in Your Hands

**TypeScript でつくる、身近な AWS**

TypeScript、HTTP、Git、Web アプリの開発には慣れているけれど、AWS のアカウント、IAM、ネットワーク、料金、運用にはまだ触れたことがない開発者に向けて書いた本です。

Cloudflare や Vercel からの乗り換えを勧める本ではありません。どちらも始めやすく、開発体験のよいプラットフォームです。この本が目指しているのは、そこに AWS を加えて、作るものに合わせて選べるようにすることです。AWS のほうが常に安い、速い、優れているとは書きません。

読み終えたときに、自分が作ったものについて次のことを説明できるようになることを目標にしています。

- 何を作ったか、なぜその構成にしたか
- コードがどこで動いているか
- 何に料金がかかるか
- 手元で確かめられることと、実環境でしか確かめられないこと
- 本番で使うなら何を足すか

## 書けている範囲と、確かめた範囲

章は 00 から 69 までの 69 章で、65 は欠番です。すべての章に本文とサンプルがあります。ただし、書き上げたことと、動かして確かめたことは別で、確かめたのは手元のマシンで実行できる範囲までです。

- [00 Introduction](/ja/chapters/00-welcome.md)から [24 Self-hosting](/ja/chapters/24-celld.md)まで、どの章も手元の検査（`vp run check:all`）に通っています。検査の中身は、format と lint、型検査、テスト、CDK の synth、Lambda のバンドルの読み込み、本のビルドとリンクの検査です
- 25章から先の 44 章は、章ごとにテストなどを手元で実行しました。何を実行したかは章によって違います。69 章がそろった状態でも、`vp run check:all` は通っています（2026-10-13）
- AWS には、どの章もまだ一度もデプロイしておらず、実行もしていません。本文にあるデプロイ後の手順は用意しただけで、通して実行できていません
- この本のサイトもまだ公開しておらず、公開 URL はありません

手元で確かめた内容は章によって違い、テストだけの章もあれば、サーバーを起動して `curl` やブラウザで操作した章もあります。64章の workerd や 66章の YugabyteDB のように、実物のソフトウェアを手元で起動した章もあります。章ごとの内訳は、各章の末尾にある「この章の検証メモ」に書きました。どのコマンドをいつ実行して何が通ったか、何がまだ残っているかは、[検証記録](/ja/reference/validation.md)にまとめてあります。

## 読みはじめる場所

- 順番に読むなら [00 Introduction](/ja/chapters/00-welcome.md) から。00章から 24章までは、順に読むように書いてあります
- 1 つの主題を深めたいなら、25章から先の章。それぞれ独立していて、サイドバーに主題ごとに並んでいます。前提にする章は、各章の冒頭にあります
- Cloudflare の D1、Workers、Workers AI に慣れているなら [Cloudflare から来た人へ](/ja/guides/cloudflare.md)
- 本番に出す前に点検したいなら [33 Production Readiness](/ja/chapters/33-production-readiness.md)
- 冪等性や競合など、分散システムの話題を章をまたいで追いたいなら [章ごとの状態と不変条件](/ja/guides/distributed.md)
- この本のサイトを同じ構成で作り直してみたいなら [本のサイトを再現する](/ja/reference/book-site.md)

## コードの置き場所

本文で説明するコードは、すべてこの本と同じリポジトリにあります。本文に載っているコードは実際のファイルから取り込んだもので、説明のために書き直した断片ではありません。どの節がどのファイルに対応するかは、各章の末尾に載せています。
