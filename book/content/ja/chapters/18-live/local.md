# 18 Live Streaming: 手元で動かす

## 手元で確かめられること

<!-- section: 18.local -->

映像を受ける場所は AWS にしかないので、ライブ配信を手元だけで完結させることはできません。それでも、かなりの部分は手元で確かめられます。

```bash
vp run test:unit
vp run stream:infra:synth
vp run dev:stream:web
```

`dev:stream:web` を実行すると、<http://localhost:5183> で視聴ページが開きます。チャンネルをまだ作っていないので「No channel is configured」と表示されるだけですが、これが正しい動きです。

テストが確かめているのは次のことです。

| どこ | ファイル | 見ているもの |
| --- | --- | --- |
| チャンネルの設定 | `test/channel.test.ts` | ビットレートと解像度が type の上限に収まるか。サーバーの URL に鍵が混ざらないこと |
| 配信の状態 | `test/stream.test.ts` | 「オフライン」と「わからない」を混ぜないこと。入力時間の数え方 |
| イベント | `test/events.test.ts`、`test/timeline.test.ts` | イベントの形の検証。順序が入れ替わっても、重複しても、結論が変わらないこと |
| 視聴ページ | `web/src/viewer.test.ts` | 404 をオフラインとして扱うこと。再試行の間隔。設定の検証 |
| インフラ | `infra/test/live-stack.test.ts` | 鍵の値がテンプレートに現れないこと。権限、録画なし、削除の設定、リソースの種類 |

手元で再現できないものは次の 4 つです。

- 実際の配信と視聴。映像が届くか、何秒遅れるか、プレイヤーが本当に再生するかは、手元ではわかりません
- IVS の API の実際の応答。`GetStream` の応答とイベントの形は、ドキュメントの例をもとにスキーマを書いています
- IAM。スクリプトはあなたの権限で動きます
- OBS の設定。手作業です

この章は、実機ではまだ一度も配信していません。手元で確かめた範囲は、[費用、注意点、片付けのページ](/ja/chapters/18-live/wrap.md)の終わりにある「この章の検証メモ」にまとめました。
