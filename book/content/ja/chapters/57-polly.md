# 57 Polly: ノートを読み上げる

Amazon Polly は、文章を音声にするサービスです。料金は合成した文字数で決まり、同じ文章をもう一度合成すれば、もう一度かかります。ところが、同じ文章を同じ声で合成した音声は、何度作っても同じ用途に使えます。この章が扱うのはその 1 点で、ノートに「聞く」ボタンを付け、**同じ文章は 1 回しか合成しない**ようにします。

音声は S3 に置き、文章と声から計算したハッシュをキーにします。2 人が同時に同じノートを開いてボタンを押しても Polly を呼ぶのは 1 回だけ、という条件まで守ります。長いノートを 1 回のリクエストに収まる大きさに分けること、利用者の書いた文章が合成の指示として解釈されないようにすることも、あわせて扱います。

前提は [07章](/ja/chapters/07-uploads.md)（S3 と署名付き URL）と [17章](/ja/chapters/17-ai.md)（function URL と、外のサービスを呼ぶ関数の作り）です。コードは `examples/57-polly/` にあります。Polly は 1 回も呼んでいません。声の聞こえ方や合成にかかる時間は、この章からは分かりません。

## 全体像

<!-- section: 57.overview -->

```figure
caption: 音声が S3 にあれば Polly を呼ばない。聞く人は、関数が署名した URL で S3 から直接受け取る
node browser: Browser | 「聞く」ボタン
node fn: Lambda | function URL
node s3: S3 バケット | speech/ と claims/
node polly: Polly | SynthesizeSpeech
edge browser -> fn: POST /speech
edge fn -> s3: HEAD、条件付きの PUT
edge fn -> polly: 音声が無いときだけ
edge fn --> browser: 署名付き URL の並び
edge browser -> s3: GET
mark s3
```

ボタンを押すと、ブラウザはノートの題と本文を `POST /speech` で送ります。関数はノートをいくつかの部分に分け、部分ごとに、音声が S3 にあるかを調べます。あればそのまま使い、無ければ Polly で合成して S3 に置きます。レスポンスは、部分ごとの署名付き URL を読む順に並べたものです。ブラウザは、その URL を順に再生します。

関数が音声そのものを返さないのは、2 回目以降の再生で関数も Polly も通さずに済ませるためです。署名付き URL の考え方は 07章と同じで、バケットは公開せず、関数のロールが署名した URL だけが、期限つきで読めます。

置いてあるだけで料金がかかるものは、このスタックにはありません。誰も聞かない月の料金は 0 で、聞かれた月の料金は、ほぼ Polly の文字数で決まります。金額は[最後のページ](/ja/chapters/57-polly/wrap.md)にあります。

## Polly でできること

<!-- section: 57.polly -->

この節の内容は、2026-10-13 に読んだ Polly のデベロッパーガイドと料金ページによります。

**エンジンと声。** Polly には合成のしくみが 4 種類あり、エンジンと呼びます。声（voice）ごとに、使えるエンジンが決まっています。

| エンジン | 100 万文字あたり | 日本語の声 | 東京リージョン |
| --- | --- | --- | --- |
| standard | 4 USD | Mizuki、Takumi | 使える |
| neural | 16 USD | Takumi、Kazuha、Tomoko | 使える |
| long-form | 100 USD | 無い（英語とスペイン語だけ） | 使えない（us-east-1 だけ） |
| generative | 30 USD | 無い | 使えるが、日本語の声が無い |

日本語で選べるのは standard と neural です。standard は録音した音の断片をつなぐ方式で、neural はニューラルネットワークで波形を作る方式だと説明されています。料金は 4 倍違います。この章は neural の Kazuha を既定にし、standard の Mizuki も選べるようにしました。英語のノートのために、en-US の Joanna（neural）も入れています。

東京リージョンの Price List に載っているのは、standard と neural の 2 つの単価だけでした。generative は東京で使えるとドキュメントにありますが、東京の単価は Price List では確認できていません。

**すぐ返る合成と、あとで届く合成。** `SynthesizeSpeech` は、リクエストに対して音声のストリームをそのまま返します。1 回に送れるのは、課金対象の文字で 3,000、タグを含めた全体で 6,000 までで、返る音声は 10 分で打ち切られます。`StartSpeechSynthesisTask` は非同期の合成で、課金対象の文字で 100,000（全体で 200,000）まで受け付け、できあがった音声を指定した S3 バケットに書き込みます。終わったことは、SNS のトピックで受け取れます。

generative のエンジンには、文章を少しずつ送りながら音声を受け取る `StartSpeechSynthesisStream` もあります。使えるリージョンに東京は入っていません。

**出力の形式。** 音声は `mp3`、`ogg_vorbis`、`ogg_opus`、`pcm`、`mulaw`、`alaw` から選びます。この章は `mp3` を使います。`OutputFormat` を `json` にすると、音声の代わりに speech marks が返ります。speech marks は、文や単語が音声の何ミリ秒目から始まるかを 1 行ずつの JSON で表したもので、読んでいる箇所を画面で目立たせるときに使います。speech marks のリクエストは、音声のリクエストとは別に、同じ文字数で課金されます。generative のエンジンでは使えません。

**SSML。** 文章は、そのままのテキストでも、SSML でも送れます。SSML は、`<speak>` で囲んだ XML に、間（`<break>`）や読み方（`<phoneme>`、`<sub>`）の指示をタグで書き込む形式です。タグは課金対象の文字に数えられません。使えるタグはエンジンによって違い、neural では `<emphasis>` や息つぎの音は使えません。この章が使うタグは、題と本文のあいだに間を入れる `<break>` だけです。

**レキシコン。** 特定の単語の読み方を登録しておく発音辞書です。W3C の PLS の形式で書き、リージョンごとに保存して、合成のリクエストで名前を指定します。1 つのアカウントに 100 個まで、1 回のリクエストに 5 個まで使えます。社名や製品名の読みを直したいときの道具ですが、この章では使っていません。CloudFormation にレキシコンのリソースがあるかどうかも確かめていません。

**クォータ。** `SynthesizeSpeech` は、neural の声で毎秒 8 リクエスト（バーストで 10）、同時に 18 リクエストまでです。standard は毎秒 80 です。超えたリクエストは `ThrottlingException` で断られます。引き上げを申請できるクォータは、コンソールから申請します。クォータの考え方は [32章](/ja/chapters/32-limits.md)にあります。

## この構成にしなくてよい場合

<!-- section: 57.alternatives -->

**ブラウザに読ませる。** ブラウザには Web Speech API の `speechSynthesis` があり、端末に入っている声で文章を読み上げられます。サーバーも料金も要らず、文章を AWS に送ることもありません。声の種類と質は端末とブラウザによって違い、声によっては端末の外のサービスで合成されます。どの端末でも同じ声で聞かせる必要が無ければ、まずこれで足ります。

**非同期の合成に任せる。** 1 つの文章が 3,000 文字を大きく超え、1 本の音声ファイルがほしいなら、`StartSpeechSynthesisTask` のほうが素直です。分割もつなぎ合わせも Polly が受け持ち、結果は S3 に届きます。その代わり、ボタンを押してすぐには聞けません。この章のノートは最大でも 1 万文字ほどなので、同期の合成を部分ごとに呼び、最初の部分からすぐ再生できるほうを選びました。

**キャッシュしない。** 文章が毎回違うなら、キャッシュは当たりません。チャットの返答を読み上げるような用途では、`SynthesizeSpeech` のストリームを、17章のレスポンスのストリーミングでそのまま流すほうが、最初の音が早く出ます。S3 に置くのは、同じ文章が繰り返し聞かれるときに意味があります。

**standard の声にする。** 料金が 4 分の 1 になります。聞き比べていないので、どちらで足りるかはこの章からは言えません。Polly のコンソールで、自分のノートの文章を両方の声で聞いて決めてください。
